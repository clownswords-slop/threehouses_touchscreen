## Known risks
- (session 16) The tutorial check on G+0x302e1 runs before every screen handler: if that flag ever stays set after a pop-up closes, every tap would press B (seen clearing on the tea party tutorial and Guide pages).
- `status_tap`, `quest_detail_tap`, `talk_tap`, `book_tap`, `house_tap` key on widget vis bytes; if one stays set after its screen closes, taps elsewhere could be swallowed. `house_tap` also requires the event scene and the picker's focus bits; `appearance_screen` in swap mode requires the list state 5, its focus bits and no free-roam HUD.
- `hand_chase` presses Right when the tap is > 165 px right of the hand; on wide items it may step into the next column and come back (correct result, extra movement).
- Map area taps assume the 64000/32000 scales; the offset is calibrated from the selected marker each tap.
- Picker rule (help bar up, no hand: side taps = Left/Right) still applies to unhandled screens.

## Tips and gotchas
- **Navigation by tap must be instant wherever possible** (user request): when a tap moves a selection, cursor, tab or page, set the target directly (SetIndex / SetColumn, the screen's own index or tab field, the game's select function) and take at most one real d-pad step so the game runs its own update; do not walk there with repeated d-pad presses (`hand_chase`) or wait out animations when a direct write works. Walking is a last resort for screens where no direct way is known; note those in "open" so they can be revisited.
- Never run a new game past the birthday with blind A/Yes scripts. Never save over the autosave, File 1, File 2 or File 7, and remember the game autosaves on its own (see Saves).
- Taps that fall through to the default A can confirm things (a stray tap picked a house in session 7); check a screen's handler before tapping blindly.
- Full-memory scans can drop Ryujinx to 1 FPS or crash it; prefer `range`, `msnap`/`mdiff`, `wscan`. `snap` stops at 4 M candidates, so narrow the range.
- Injected `btn` presses need 8-20 frames. computer_zoom takes a fresh capture.
- Clean-up when finished: `sdcard\touchmod` (debug channel files) and `screenshots` can be deleted (needs delete permission).
